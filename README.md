📌 Project Introduction

The EV Charging Network Dashboard is an interactive Power BI
business intelligence project designed to analyze electric vehicle
charging operations, station performance, revenue generation, energy
consumption, customer segments, charger utilization, session outcomes,
and environmental impact.

The project converts raw EV charging data from CSV files into a
structured analytical report using Power Query, data modeling, DAX
measures, KPI cards, charts, slicers, and interactive Power BI
visuals.

The dashboard is designed for three levels of analysis:

Executive Overview -- high-level business and financial
performance.

Stations & Charging Operations -- operational performance and
charging activity.

Station Performance Details -- detailed station-level analysis.

🎯 Project Objectives

The main objectives of this project are to:

Monitor total revenue generated by the EV charging network.

Track total charging sessions.

Measure total energy consumed.

Analyze average session value.

Measure average charging duration.

Monitor CO₂ emissions saved.

Compare completed, failed, and cancelled sessions.

Analyze customer segments.

Study charging duration versus energy consumption.

Support operational and business decision-making through interactive

🧮 DAX Measures / Calculations

The project uses DAX measures to calculate the major KPIs and analytical
metrics.

Important: The measure names below are documentation-friendly
names based on the dashboard. If your actual .pbix uses different
measure names, keep your existing names or rename them consistently.

Total Revenue

Total Revenue =
SUM('EV Data'[Revenue])

Total Charging Sessions

Total Charging Sessions =
COUNTROWS('EV Data')

Total Energy

Total Energy =
SUM('EV Data'[Energy Consumed])

Average Session Value

Average Session Value =
DIVIDE(
    [Total Revenue],
    [Total Charging Sessions],
    0
)

Average Charging Duration

Average Charging Duration =
AVERAGE('EV Data'[Duration (Min)])

Total CO₂ Saved

Total CO2 Saved =
SUM('EV Data'[CO2 Saved])

Completed Sessions

Completed Sessions =
CALCULATE(
    [Total Charging Sessions],
    'EV Data'[Session Status] = "Completed"
)

Failed Sessions

Failed Sessions =
CALCULATE(
    [Total Charging Sessions],
    'EV Data'[Session Status] = "Failed"
)

Cancelled Sessions

Cancelled Sessions =
CALCULATE(
    [Total Charging Sessions],
    'EV Data'[Session Status] = "Cancelled"
)

Cancellation Rate

Cancellation Rate =
DIVIDE(
    [Cancelled Sessions],
    [Total Charging Sessions],
    0
)

Peak Revenue

Peak Revenue =
CALCULATE(
    [Total Revenue],
    'EV Data'[Peak/Off-Peak] = "Peak"
)

Off-Peak Revenue

Off-Peak Revenue =
CALCULATE(
    [Total Revenue],
    'EV Data'[Peak/Off-Peak] = "Off-Peak"
)

Average Energy per Session

Average Energy per Session =
DIVIDE(
    [Total Energy],
    [Total Charging Sessions],
    0
)

🔍 Key Business Insights

Based on the dashboard visuals, the report can be used to identify:

Revenue

The network generates substantial revenue across different cities,
stations, charger types, customer segments, and time periods.

Station Performance

The Top 5 Stations visual highlights stations generating the highest
revenue, while the Top 10 Stations by Sessions visual identifies
stations with the highest charging activity.

Charger Performance

Different charger types contribute differently to network revenue and
session volume. This allows management to compare AC Fast, AC Slow, DC
Fast, and DC Ultra-Fast infrastructure.

Customer Segments

The customer segment analysis shows how different customer groups
contribute to the overall business.

Session Status

The Station Operations page separates charging sessions into:

Completed

Failed

Cancelled

This helps identify operational issues and service reliability.

Charging Demand

The hourly demand chart helps identify periods with higher charging
activity, which can support capacity planning and station utilization
decisions.

Energy Consumption

The duration-versus-energy analysis helps understand the relationship
between charging time and energy consumption for different charger
technologies.

Environmental Impact

The Total CO₂ Saved KPI provides an environmental-performance
indicator for the EV charging network.
